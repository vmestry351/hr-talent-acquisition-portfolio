# Talent Acquisition Toolkit

Three documents that cover the hiring process from job description to offer. All content uses mock data.

| File | Contents |
|------|----------|
| `JD_and_Screening_Toolkit.docx` | Job descriptions for Sales Executive and HR Intern, knockout checklists, weighted scoring sheets and scored mock candidates |
| `Structured_Interview_Kit.docx` | 12-question interview bank across 6 competencies, 1-5 rating guide, scorecard and a two-interviewer scoring example |
| `Candidate_Sourcing_Plan.docx` | 30-day sourcing plan for a Junior Data Analyst role: channels, Boolean search strings, outreach templates, follow-up cadence, funnel and metrics |
